# OpsDesk — Project Rules for Claude

## What this project is
This is my OpsDesk internship Week 1 project: React + Vite, plain JavaScript,
plain CSS. No build-tool or framework additions beyond this.

## Dependencies and tooling
- Do not add TypeScript, React Router, or any new npm package without asking me
  first. Routing and TypeScript come next week.

## Git workflow
- Never commit or push directly to `main`.
- Every piece of work goes in this order: GitHub issue → feature branch →
  pull request.
- Keep commits small, with clear messages that say what changed.

## Code style
- Keep components small and focused.
- One component per file.

## How to communicate with me
- After every change, explain in plain language what you did and why, so I can
  explain it to my supervisor.
